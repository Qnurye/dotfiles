# Review triage

Read each unresolved GitHub thread against the current head and its intended base. Identify the behavior the reviewer expects, inspect all callers including dependent PRs, and reproduce the issue where possible. Record the command or code location supporting the verdict.

Fix confirmed issues within scope. For stale or inapplicable findings, give the exact revision and the evidence. Keep uncertain findings open with the missing information. The same standard applies to human and automated reviews.
